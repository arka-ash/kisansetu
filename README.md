# 🌾 KisanSetu

**AI-assisted market linkage and price discovery platform for farmers.**

KisanSetu helps farmers discover potential buyers, compare prices, estimate net returns, and make informed selling decisions.

## Features

* 👨‍🌾 Farmer profile and produce listings
* 🤝 AI-assisted buyer matching
* 💰 Buyer price comparison
* 📊 Estimated net return calculation
* 📍 Location-aware buyer matching
* 🤖 AI-powered decision support
* 🚚 Transport and storage requests
* 📩 Digital offers between farmers and buyers

## Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Backend:** Node.js, Express
* **Database:** Supabase / PostgreSQL
* **AI:** Google Gemini API
* **Maps & Location:** Browser Geolocation / Maps



> **Note:** This is an SIH prototype. Some buyer, price, logistics, and market information is representative demo data. Production deployment would integrate verified external data sources and services.
